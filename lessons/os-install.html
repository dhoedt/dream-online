Installer un système d'exploitation

Le support bootable

L'installation d'un système d'exploitation (OS, de l'anglais Operating System) se faisait, à l'époque, à l'aide d'un DVD qu'on achetait dans le commerce.

Ce DVD n'est pas comme les autres : il contient les informations nécessaires à l'ordinateur pour démarrer dessus. On appelle ça un DVD bootable (« démarrable ») : c'est un DVD que le firmware (BIOS, UEFI) peut démarrer comme s'il démarrait un OS.

Au démarrage, un installateur permettait alors à l'utilisateur d'installer l'OS selon ses goûts :

  • nom d'utilisateur ;
  • nom du PC ;
  • mot de passe ;
  • comptes supplémentaires, etc.

Aujourd'hui, les lecteurs DVD se font rares : il faut donc utiliser un autre type de stockage, la clé USB.

Le fichier ISO

Cette clé USB contient les mêmes fichiers qu'un DVD d'installation, ce qui permet à l'ordinateur de démarrer dessus de la même manière.

Ces fichiers sont fournis sous la forme d'un fichier ISO (extension .iso) : un fichier qui contient une copie exacte du contenu d'un disque optique (p. ex. CD, DVD ou Blu-ray) ; on l'appelle aussi une image disque.

La création d'une clé USB bootable à partir d'une simple clé USB du commerce est décrite ci-dessous.

Media Creation Tool

Le Media Creation Tool est l'outil officiel de Microsoft, à télécharger sur microsoft.com. Il sert uniquement à installer Windows.

Au lancement, l'outil demande quel support utiliser :

  • Clé USB (USB flash drive) : l'outil crée directement une clé USB bootable. La clé doit faire au moins 8 Go.
  • Fichier ISO (ISO file) : l'outil télécharge l'image disque de Windows, qu'il faudra ensuite graver sur un DVD (ou mettre sur une clé USB avec un autre outil, comme Rufus).

Rufus

Rufus est un logiciel libre et open source, sans aucun lien avec Microsoft. C'est un utilitaire qui permet de créer des clés USB démarrables à partir d'une image ISO démarrable (p. ex. Windows, Linux, etc.).

Rufus a besoin d'un fichier ISO : il faut d'abord le télécharger sur le site officiel de l'OS (p. ex. microsoft.com pour Windows), puis le choisir dans Rufus avec le bouton Sélection.

Rufus crée uniquement des clés USB : il ne grave pas de DVD.

Récapitulatif : obtenir un support bootable

  • Depuis microsoft.com, on peut télécharger directement le fichier ISO de Windows, ou le Media Creation Tool.
  • Le Media Creation Tool produit au choix :
    • un fichier ISO ;
    • une clé USB bootable.
  • Rufus, associé à un fichier ISO, produit une clé USB bootable.

Le DVD bootable existe encore mais est devenu rare : aujourd'hui, on utilise presque toujours une clé USB.

Récapitulatif : installer l'OS

1Démarrage

On branche la clé USB bootable et on allume le PC.

2Firmware (BIOS / UEFI)

Le premier programme qui s'exécute est le firmware de la carte mère (BIOS ou UEFI). C'est lui qui choisit sur quel support démarrer : il faut qu'il démarre sur la clé USB.

Pour ce faire, il faut ouvrir le menu de démarrage (souvent avec une touche comme F12, F11 ou Échap, selon le fabricant) ou modifier l'ordre de démarrage dans les réglages du firmware.

3Clé USB bootable

Le PC démarre sur la clé, qui lance le programme d'installation de l'OS.

4Installation sur le disque (HDD / SSD)

Le programme d'installation copie l'OS sur le disque dur (HDD) ou le SSD de l'ordinateur. Une fois l'installation terminée, on peut retirer la clé : le PC démarrera désormais directement sur son disque et lancera l'OS qui y est installé.
